# Phoenix Stem Studio — iPhone edition

This folder contains a browser-based *local-audio* mixer and rough monophonic MIDI estimation tool. It is not an iPhone IPA and is not the upstream StemForge project. Audio chosen using the file picker stays in the phone/browser: no music or stems are uploaded to this repository.

Open the deployed GitHub Pages site on iPhone Safari; Share → Add to Home Screen. Import MP3 or M4A stems extracted in Files. The MIDI drafts need musical verification. Do not treat them as finished instrument reconstructions.

Never commit unreleased music, stem files, lyrics or sensitive data to this public repository.
